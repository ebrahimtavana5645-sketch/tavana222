# راه‌اندازی شمارندهٔ نصب (رایگان، فقط یک بار، حدود ۵ دقیقه)

هر دستگاه یک شناسهٔ تصادفی ناشناس دارد. هنگام باز شدن برنامه (حداکثر روزی یک بار) شناسه + نوع دستگاه
(apk / exe / pwa / web) + نسخهٔ برنامه به یک Google Sheet **متعلق به خود شما** ارسال می‌شود. نام، شماره یا مکان ارسال نمی‌شود.

## مراحل
1. در Google Drive یک Google Sheet خالی بسازید (مثلاً «آمار اوقات شرعی»).
2. منوی **Extensions ← Apps Script** را باز کنید، محتوای پیش‌فرض را پاک کنید و کل فایل `Code.gs` را جای‌گذاری کنید و Save بزنید.
3. در Apps Script: **Project Settings ← Script properties ← Add script property**
   نام: `ADMIN_KEY` ، مقدار: یک رمز دلخواه و طولانی (فقط خودتان). 
4. **Deploy ← New deployment ← نوع: Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   سپس Deploy بزنید و اجازه‌ها را تأیید کنید. نشانی «Web app URL» (به `/exec` ختم می‌شود) را کپی کنید.
5. فایل `stats-config.js` کنار `index.html` را باز کنید و نشانی را بگذارید:
   `window.OWQAT_STATS_URL = 'https://script.google.com/macros/s/.../exec';`
6. APK و EXE را دوباره بسازید (یا فایل‌ها را روی میزبان بگذارید). از این پس هر نصب جدید ثبت می‌شود.

## دیدن آمار
- فایل `admin-stats.html` را در مرورگر باز کنید، نشانی Web app و `ADMIN_KEY` را وارد کنید (این فایل داخل APK/EXE نمی‌رود).
- یا مستقیم Google Sheet را باز کنید: هر سطر یک دستگاه است.

## معنی عددها
- **تعداد نصب** = APK + EXE + «افزودن به صفحهٔ اصلی» (PWA).
- «فقط بازدید مرورگر» کسانی‌اند که برنامه را در تب مرورگر باز کرده‌اند و نصب نکرده‌اند.
- اگر کاربر برنامه را حذف و دوباره نصب کند، شناسهٔ تازه می‌گیرد و یک نصب جدید حساب می‌شود؛ پاک کردن اطلاعات برنامه هم همین‌طور.
- اگر دستگاه اینترنت نداشته باشد، شمارش در اولین باز شدن بعدی با اینترنت انجام می‌شود.

## نکتهٔ مهم
اگر Apps Script را بعد از تغییر کد دوباره Deploy می‌کنید، گزینهٔ **Manage deployments ← Edit ← New version** را بزنید تا نشانی تغییر نکند.

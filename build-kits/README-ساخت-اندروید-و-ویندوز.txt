راهنمای ساخت APK (اندروید) و EXE (ویندوز) — اوقات شرعی / Tavana
==================================================================
توجه: این مراحل در محیط ساخت من آزمایش نشده‌اند (آنجا Android SDK، Electron و اینترنت نبود)؛
پروژه‌ها آمادهٔ ساخت هستند و روی کامپیوتر یا GitHub شما ساخته می‌شوند.

راه ۱ (ساده‌ترین، بدون نصب چیزی): ساخت خودکار روی GitHub — هم APK هم EXE
---------------------------------------------------------------------------
۱) در github.com یک حساب رایگان بسازید و یک مخزن (Repository) جدید، مثلاً tavana، بسازید.
۲) محتوای همین پوشهٔ برنامه (index.html، پوشهٔ build-kits، پوشهٔ .github و ...) را در ریشهٔ مخزن آپلود کنید
   (Add file > Upload files). مطمئن شوید پوشهٔ .github هم بالا رفته است.
۳) تب Actions > «build-apk-exe» > Run workflow را بزنید.
۴) بعد از حدود ۱۰ تا ۱۵ دقیقه، پایین صفحهٔ اجرا در بخش Artifacts دو فایل می‌بینید:
   owqat-apk  (فایل app-debug.apk)   و   owqat-exe  (نصب‌کننده و نسخهٔ portable).
   دانلود و از حالت زیپ خارج کنید.

راه ۲: ساخت EXE روی ویندوز خودتان
----------------------------------
۱) Node.js نسخهٔ 18 یا بالاتر را از nodejs.org نصب کنید.
۲) روی فایل «build-kits\ساخت-EXE-ویندوز.bat» دوبار کلیک کنید (یا در پوشهٔ build-kits\windows:
   npm install  و سپس  npm run dist).
۳) خروجی در build-kits\windows\dist: یک نصب‌کنندهٔ Setup و یک فایل portable (بدون نصب).
   فقط برای آزمایش بدون ساخت: npm start

راه ۳: ساخت APK روی ویندوز خودتان
----------------------------------
۱) Node.js، JDK 17 و Android Studio (برای Android SDK) را نصب کنید.
۲) روی «build-kits\ساخت-APK-اندروید.bat» دوبار کلیک کنید.
   APK در build-kits\android\android\app\build\outputs\apk\debug\app-debug.apk ساخته می‌شود.
   (یا دستی: npm install ، npm run prepare-web ، npx cap add android ، node apply-icons.js ،
   npx cap sync android ، و در Android Studio: Build > Build APK(s)).

نصب APK روی گوشی: فایل را به گوشی بفرستید و «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل مجاز کنید.
APK ساخته‌شده «debug» است و برای نصب شخصی کافی است. برای انتشار در فروشگاه (Google Play / بازار / مایکت)
باید با keystore خودتان امضا شود (Android Studio > Build > Generate Signed Bundle / APK).

راه بدون ساخت APK: روی گوشی در Chrome برنامه را باز کنید و «افزودن به صفحهٔ اصلی» را بزنید، یا
با pwabuilder.com از آدرس سایت‌تان APK بگیرید.

نکتهٔ آفلاین بودن
-----------------
برنامه برای ساخت عکس، PDF و اکسل از سه کتابخانهٔ اینترنتی (CDN) استفاده می‌کند و فونت‌ها از Google Fonts می‌آیند:
html2canvas 1.4.1، jsPDF 2.5.1، SheetJS (xlsx) 0.18.5. بدون اینترنت، خروجی عکس/PDF/اکسل در EXE و APK کار نمی‌کند.
برای نسخهٔ کاملاً آفلاین این فایل‌ها را دانلود کنید، کنار index.html بگذارید و نشانی آن‌ها را در index.html عوض کنید
(اگر خواستید، همین کار را برایتان انجام می‌دهم).
